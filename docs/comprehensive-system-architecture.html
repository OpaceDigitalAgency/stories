Stories from the Web – System Architecture

Version updated: 27 April 2025 – consolidated from system‑architecture.html, comprehensive‑system‑architecture.md and related docs.

1. Overview

Stories from the Web is a two‑tier publishing platform.

  • Public Frontend – Static Astro TS/TW site served via Netlify CDN.
  • Admin Backend – PHP CMS on cPanel shared hosting (JavaScript‑free UI).

Key Benefits

  • Separation of Concerns – Frontend and backend can be developed independently
  • Scalability – Each component can be scaled separately
  • Security – Admin interface is isolated from public frontend
  • Performance – Static frontend with dynamic data loading

7. Security & Compliance

  • Bcrypt password hashing & rate‑limit on failed logins
  • Strict PSR‑4 autoloader (case‑sensitivity enforced)
  • Content‑Security‑Policy blocks JS in Admin
  • SQL‑prepared statements & XSS sanitisation
