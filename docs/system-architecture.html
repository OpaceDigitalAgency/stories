    Frontend Deployment (Netlify)

    Configuration (netlify.toml)

    [build]
  command = "npm run build"
  publish = "dist"

[build.environment]
  PUBLIC_API_URL = "https://api.storiesfromtheweb.org/api/v1"

[context.production.environment]
  PUBLIC_API_URL = "https://api.storiesfromtheweb.org/api/v1"

[context.deploy-preview.environment]
  PUBLIC_API_URL = "https://api.storiesfromtheweb.org/api/v1"

    Deployment Process

    1. Developer pushes changes to GitHub repository
    2. Netlify automatically detects changes
    3. Netlify runs the build command: npm run build
    4. Astro generates static HTML, CSS, and JavaScript
    5. Files are deployed to Netlify's CDN
    6. Site is available at https://storiesfromtheweb.netlify.app/

    Backend Deployment (cPanel Git Version Control)

    Configuration (.cpanel.yml)

    ---
deployment:
  tasks:
    - export DEPLOYPATH=/home/stories/api.storiesfromtheweb.org/
    - /bin/cp -R stories-backend/check_auth_status.php $DEPLOYPATH
    - /bin/cp -R stories-backend/direct_login.php $DEPLOYPATH
    - /bin/cp -R stories-backend/go_to_dashboard.php $DEPLOYPATH
    - /bin/cp -R stories-backend/logout.php $DEPLOYPATH
    - /bin/cp -R stories-backend/.htaccess $DEPLOYPATH
    - /bin/cp -R stories-backend/admin $DEPLOYPATH
    - /bin/cp -R stories-backend/api $DEPLOYPATH

    Deployment Process

    1. Developer pushes changes to GitHub repository
    2. Administrator logs in to cPanel
    3. Navigates to Git Version Control
    4. Selects the "stories" repository
    5. Clicks "Update from Remote" to pull latest changes
    6. Clicks "Deploy HEAD Commit" to deploy
    7. Files are copied according to .cpanel.yml configuration
    8. Changes are live at https://api.storiesfromtheweb.org/

    Access Details

    • cPanel URL: https://cpanel.storiesfromtheweb.org/
    • Username: Contact administrator for credentials

    Server Configuration

    Apache Configuration (.htaccess)

    # Protect sensitive files

    Order allow,deny
    Deny from all


# Allow access to specific PHP files

    Order allow,deny
    Allow from all


# Enable CORS for API

    Header set Access-Control-Allow-Origin "https://storiesfromtheweb.netlify.app"
    Header set Access-Control-Allow-Methods "GET, POST, PUT, DELETE, OPTIONS"
    Header set Access-Control-Allow-Headers "Content-Type, Authorization"
    Header set Access-Control-Allow-Credentials "true"


# Handle preflight OPTIONS requests
RewriteEngine On
RewriteCond %{REQUEST_METHOD} OPTIONS
RewriteRule ^(.*)$ $1 [R=200,L]

    Deployment Best Practices

    • Version Control: All changes must be committed to Git
    • Testing: Test changes in staging environment first
    • Backups: Create database backups before major changes
    • Monitoring: Monitor logs and performance after deployment
    • Rollback Plan: Have a plan for rolling back changes if needed
