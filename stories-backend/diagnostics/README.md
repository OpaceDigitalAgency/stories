# Diagnostic Tools for Stories from the Web

This directory contains all diagnostic tools for the Stories from the Web platform. These tools are essential for troubleshooting and maintaining the system.

## Directory Structure

- `/api` - API testing and diagnostic tools
- `/auth` - Authentication testing and diagnostic tools
- `/admin` - Admin interface testing and diagnostic tools
- `/database` - Database testing and diagnostic tools
- `/system` - System-level testing and diagnostic tools
- `/docs` - Documentation for diagnostic tools
- `/media` - Media system diagnostic tools

## Important Notes

1. **DO NOT DELETE OR MOVE** these diagnostic tools. They are critical for system maintenance.
2. All diagnostic tools should be accessible from the main diagnostic dashboard at `/diagnostic-dashboard.php`.
3. If you create a new diagnostic tool, please add it to the appropriate directory and update the dashboard.
4. All diagnostic tools should include proper error handling and clear instructions for use.

## Usage

Access the diagnostic dashboard at: https://api.storiesfromtheweb.org/diagnostic-dashboard.php

## Documentation

For detailed documentation on each diagnostic tool, see the `/docs` directory or the comments within each file.
