## Recovery Process

If you need to recover a document from this archive, you can:

1. Copy the document back to its original location:
   ```bash
   cp stories-backend/docs/_archive/[document_name] stories-backend/docs/
   ```

2. Or view the document's content to extract specific information:
   ```bash
   cat stories-backend/docs/_archive/[document_name]
   ```
