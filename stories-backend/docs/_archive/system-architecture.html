Overview

Stories from the Web is a platform for sharing and discovering stories, with additional features for games, directory listings, and AI tools. The platform consists of two main components:

  • Public Frontend: A user-facing website where visitors can browse and read stories, explore games, view directory listings, and discover AI tools.
  • Admin Backend: A content management system where administrators and authors can create, edit, and manage content.

Tech Stack

Frontend

  • Framework: Astro.js (v2.x)
  • Styling: Tailwind CSS
  • Language: TypeScript
  • Build Tool: Vite (integrated with Astro)
  • Package Manager: npm
  • Deployment: Netlify

Backend

  • Language: PHP (v8.3.x)
  • Database: MySQL (v8.0.x)
  • Server: Apache (on cPanel shared hosting)
  • Authentication: Custom JWT implementation
  • Deployment: cPanel Git Version Control

Key Benefits

  • Separation of Concerns: Frontend and backend can be developed independently
  • Scalability: Each component can be scaled separately
  • Security: Admin interface is isolated from public frontend
  • Performance: Static frontend with dynamic data loading

API Documentation

API Design Principles

  • RESTful: Follows REST principles for resource naming and HTTP methods
  • Consistent: All endpoints follow the same response format
  • Secure: Authentication and authorization for protected endpoints
  • Documented: Clear documentation and examples for all endpoints

Base URL

All API endpoints are relative to:

https://api.storiesfromtheweb.org/api/v1

Security

Security Measures

  • Token Security:
    • Tokens are signed with a secret key
    • Tokens have a limited lifetime
    • Tokens can be revoked by deleting from database
  • Password Security:
    • Passwords are hashed using bcrypt
    • Failed login attempts are rate-limited
    • Password reset requires email verification
  • HTTPS:
    • All API communication is over HTTPS
    • Cookies are set with Secure and HttpOnly flags
    • Content Security Policy prevents XSS attacks

Frontend Deployment (Netlify)

[build]
  command = "npm run build"
  publish = "dist"

[build.environment]
  PUBLIC_API_URL = "https://api.storiesfromtheweb.org/api/v1"

Backend Deployment (cPanel Git Version Control)

---
deployment:
  tasks:
    - export DEPLOYPATH=/home/stories/api.storiesfromtheweb.org/
    - /bin/cp -R stories-backend/admin $DEPLOYPATH
    - /bin/cp -R stories-backend/api $DEPLOYPATH

Getting Started

Setup Development Environment

# Clone repository
git clone https://github.com/OpaceDigitalAgency/stories.git
cd stories

# Install dependencies
npm install

# Start development server
npm run dev

Backend Setup

# Import database
mysql -u root -p stories_db < stories-backend/database/stories_db_26.04.25_1337.sql

# Update database configuration
# Edit stories-backend/api/v1/config/config.php
